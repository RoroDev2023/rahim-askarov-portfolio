A useful feature still needs request limits.

The plot-explanation path first sends an image URL. Its fallback converts the image to JPEG, caps the largest dimension at 1,400 pixels, and uses quality 0.85.

Documented reason
Source comments explicitly connect resizing to smaller request payloads and avoiding server errors.
Tradeoff
Compression reduces image detail. A 20-second timeout and JSON validation bound the request and check the response format.

Machine learning · Medical imaging

Knee MRI

I’m exploring how multilingual radiology reports can help train knee MRI abnormality models when official labels are scarce. The pipeline combines Qwen-based report labeling, fold-specific soft targets, and multi-plane MRI features. Report and feature extraction are complete; classifier training and validation are in progress.

Explore the code ↗
Behind the build +

Working with scarce labels

The RSNA dataset contains 4,407 studies, with complete official labels for just 58. Report-derived supervision preserves the distinction between absent findings and unknown ones.

Keeping validation separate

Identical normalized reports stay in the same fold. Soft targets use only officially labeled training studies; official labels retain full weight.

Progress & next steps

The repository records complete MRI features for 4,405 studies and a passed classifier training smoke test. Full training, per-label validation, and image-only inference remain in progress.
